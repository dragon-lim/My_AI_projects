Agent 추가 

제안 1 ) 
원문 검색으로 대조하여
llm이 완성한 필기노트를 
Agent가 검사하고 처리를 결정
(근거 없는 문장을 어떻게 처리할지만 결정)

Agent 결정은 통과 / 확인 필요 / 삭제
그리고 애매한 부분은
"확인 필요"로 표시해 학생에게 판단을 넘긴다

검증 단계에서는 LLM을 쓰지 않는다
(자기가 만든 노트이기 때문에)

"이 한 문장이 원문 어딘가에 있는가"를 묻는 작업


원문 txt 파일과 llm이 완성한 노트를 비교하여
할루시네이션 방지 및 더욱 정확한 정보


결과

무엇을
LLM이 만든 노트 ↔ 전사 원문 txt 를 문장 단위로 대조

어떻게
"이 문장이 원문 어딘가에 있는가"를 의미 기반 검색으로 확인
→ 검증에는 LLM을 쓰지 않음 (자기 검토는 신뢰할 수 없으므로 외부 원문과 대조)

Agent가 하는 일
문장을 다시 쓰지 않고, 처리만 결정 → 통과 / 확인 필요(학생에게) / 삭제

효과
강의에 없던 내용이 노트에 남지 않음 = 할루시네이션 방지
